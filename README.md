## 🚀 Sobre o Projeto
O **NEXUS** é um projeto frontend de e-commerce e suporte tecnológico criado focado em alta performance visual e interatividade. O site simula uma loja de ponta especializada em componentes de alto rendimento, consolas de última geração e serviços de manutenção.

## ✨ Funcionalidades & Destaques Visuais
* **Navbar Fixa com Scrollspy:** Navegação fluida com rastreamento automático da seção ativa no ecrã.
* **Logótipo com Efeito Neon:** Animação personalizada com (*flicker*) simulando letreiros futuristas.
* **Carrossel Interativo:** Destaque visual para os principais pilares da loja (Tecnologia, Consoles e Assistência).
* **Catálogo de Produtos:** Grelha estruturada com cartões interativos para placas de vídeo, PCs pré-montados e periféricos RGB.
* **E-mail Badge de LED:** Botão de contato exclusivo com (*Border Beam*).
* **Área de Avisos & Estatísticas:** Blocos informativos com o histórico da empresa, garantias estendidas e *live feed* de novidades.
* **Formulário de Contato:** Seção dedicada para orçamentos e dúvidas dos clientes.

## 🛠️️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Estilização avançada, variáveis, folha de estilos personalizada e animações via `@keyframes`.
* **Bootstrap 5.3:** Framework CSS para grelhas responsivas e componentes adaptáveis.
* **Git & GitHub:** Controle de versões e hospedagem em nuvem.

## 📜 Histórico de Versões (Commits)
O desenvolvimento do projeto consiste em: 
* **`v1`**: Estrutura base completa do site desenvolvida em HTML.
* **`v2`**: Implementação da camada de estilos CSS, identidade visual, efeitos de neon/LED e otimização responsiva.
