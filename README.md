# Projeto Front-End - NEXUS (TDE Parte I)

## Descrição do Projeto
disciplina de Programação Front-End da UNIFAN. A **NEXUS** é uma interface Web responsiva voltada para o comércio de hardware, games e tecnologia

## Tecnologias Utilizadas
- **HTML5** (tags semânticas  `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
- **CSS3** (utilizando Variáveis CSS, Flexbox e Media Queries).
- **Bootstrap 5** via CDN (Navbar, Carousel, Cards e Buttons).
- **Git e GitHub** para controle das versões.
- Hospedagem no **GitHub Pages**.
